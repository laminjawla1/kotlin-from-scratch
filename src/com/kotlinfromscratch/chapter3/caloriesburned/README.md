# Calories Burned

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 3, Exercise 2

## Problem
A treadmill burns 3.9 calories per minute. Use a loop to display the
calories burned after 10, 15, 20, 25 and 30 minutes.

## Sample run
```
Calories burned in 10 minutes: 39.0
Calories burned in 15 minutes: 58.5
Calories burned in 20 minutes: 78.0
Calories burned in 25 minutes: 97.5
Calories burned in 30 minutes: 117.0
```

## Concepts practiced
- Constants with `const val`
- `for` loop over a range (`10..30`)
- Counting in steps with `step`
- `Double` and `Int` arithmetic
- String formatting
