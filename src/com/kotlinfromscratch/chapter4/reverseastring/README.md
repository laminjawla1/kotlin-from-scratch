# Reverse a String

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 4, Exercise 2

## Problem
Ask the user for a string and display it reversed.

## Sample run
```
Enter a string: Hello
REVERSED: olleH
```

```
Enter a string: level
REVERSED: level
```

## Concepts practiced
- Reading console input as text
- Counting down with `downTo`
- Indexing a string with `text[i]`
- Building text with `StringBuilder`

## Notes
- Kotlin also has a built-in `reversed()` for strings. This version uses a
  loop to show how reversal works.
