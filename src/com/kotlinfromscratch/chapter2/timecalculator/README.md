# Time Calculator

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 2, Exercise 13

## Problem
Ask the user for a number of seconds and break it down into days, hours,
minutes and remaining seconds. A minute has 60 seconds, an hour has 3,600
and a day has 86,400.

## Sample run
```
Enter seconds: 180120
DAYS: 2
HOURS: 2
MINUTES: 2
SECONDS: 0
```

```
Enter seconds: 3725
DAYS: 0
HOURS: 1
MINUTES: 2
SECONDS: 5
```

## Concepts practiced
- Reading console input and safe parsing with `toIntOrNull()`
- Constants with `const val`
- Integer division (`/`) and remainder (`%`)
- `if` statements and `var` for values that change
- Error handling
