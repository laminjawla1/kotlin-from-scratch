# Roman Numeral

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 2, Exercise 1

## Problem
Ask the user for a number from 1 through 10 and display the matching Roman numeral.

## Sample run
```
Enter a number: 10
RESULT: X
```

```
Enter a number: 8
RESULT: VIII
```

## Concepts practiced
- Immutable variables with `val`
- Safe number parsing with `toIntOrNull()`
- Range checks with `in` and `!in`
- Error handling
- `when` expression
