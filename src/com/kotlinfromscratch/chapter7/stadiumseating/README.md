# Stadium Seating

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 7, Exercise 4

## Problem
A stadium has three seating classes: Class A seats cost $15, Class B seats
cost $12 and Class C seats cost $9. Ask the user how many tickets were sold
in each class, then display the revenue from each class and the total
income. The revenue calculation lives in its own function.

## Sample run
```
How many Class A tickets were sold? 10
How many Class B tickets were sold? 16
How many Class C tickets were sold? 22
CLASS A REVENUE: $150.00
CLASS B REVENUE: $192.00
CLASS C REVENUE: $198.00
TOTAL REVENUE: $540.00
```

## Concepts practiced
- Writing a function with parameters and a return value
- Constants with `const val`
- Safe number parsing with `toIntOrNull()`
- Combining validation conditions
- String formatting
