# Falling Distance

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 7, Exercise 7

## Problem
An object falling under gravity covers d = ½ × g × t² meters, where g is
9.8 and t is the falling time in seconds. Write a function named
`fallingDistance` that takes the time in seconds and returns the distance in
meters. Call it in a loop for the times 5 through 10 and display each result.

## Sample run
```
Distance after 5 seconds: 122.5 meters
Distance after 6 seconds: 176.4 meters
Distance after 7 seconds: 240.1 meters
Distance after 8 seconds: 313.6 meters
Distance after 9 seconds: 396.9 meters
Distance after 10 seconds: 490.0 meters
```
