# Test average and grade

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 7, Exercise 9

## Problem
Design a program that asks the user to enter five test scores.
The program should display a letter grade for each score and the average test score.

Design the following functions in the program:
▪ calcAverage – This function should accept five test scores as parameters and return the average of the scores.
▪ determineGrade – This function should accept a test score as a parameter and return a letter grade for the score (as
a String), based on the following grading scale:
Score Letter Grade
90–100 A
80–89 B
70–79 C
60–69 D
Below 60 F

## Sample run
```
Enter score #1: 76
Enter score #2: 89
Enter score #3: 76
Enter score #4: 45
Enter score #5: 88
SCORE: 76.0 | GRADE: C
SCORE: 89.0 | GRADE: B
SCORE: 76.0 | GRADE: C
SCORE: 45.0 | GRADE: F
SCORE: 88.0 | GRADE: B
AVERAGE: GRADE: 74.8
```
