# Feet to Inches

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 7, Exercise 6

## Problem
One foot equals 12 inches. Write a function named `feetToInches` that takes
a number of feet and returns the number of inches. Use it in a program that
asks the user for a number of feet and displays the result in inches.

## Sample run
```
Feet: 5
INCHES: 60.0
```

```
Feet: abc
ERROR: Invalid input. Please enter a positive number.
```

## Concepts practiced
- Writing a function with a parameter and a return value
- Constants with `const val`
- Safe number parsing with `toDoubleOrNull()`
- String formatting
