# Calories from Fat and Carbohydrates

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 7, Exercise 3

## Problem
Ask the user for the grams of fat and carbohydrates they ate in a day, then
display the calories from each: fat gives 9 calories per gram and
carbohydrates give 4. Each calculation lives in its own function.

## Sample run
```
Fat grams: 13.4
Carb grams: 3.9
CALORIES FROM FAT: 120.6000
CALORIES FROM CARBS: 15.6000
```

## Concepts practiced
- Writing functions with parameters and return values
- Constants with `const val`
- Safe number parsing with `toDoubleOrNull()`
- String formatting
