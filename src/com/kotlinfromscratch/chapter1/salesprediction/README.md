# Sales Prediction

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 1, Exercise 2

## Problem
A company's annual profit is typically 23 percent of its total sales.
Ask the user for the projected total sales, then display the profit
that amount would produce.

## Sample run
```
Enter Total Sales: 78659.87
Profit: 18091.77
```

## Concepts practiced
- Reading console input
- Safe parsing with `toDoubleOrNull()` and input validation
- Constants with `const val`
- Arithmetic and string formatting
