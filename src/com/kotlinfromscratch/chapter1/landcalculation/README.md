# Land Calculation

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 1, Exercise 3

## Problem
One hectare equals 10,000 square meters. Ask the user for the size of a
tract of land in square meters, then display its size in hectares.

## Sample run
```
Enter Total Square Meters: 87754.87
Hectares: 8.7755
```

## Concepts practiced
- Reading console input
- Safe parsing with `toDoubleOrNull()` and input validation
- Arithmetic and string formatting
- Numeric literals with underscores (`10_000`)
