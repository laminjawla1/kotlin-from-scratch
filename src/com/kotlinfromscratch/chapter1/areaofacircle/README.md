# Area of a Circle

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 1, Exercise 7

## Problem
Ask the user for the radius of a circle, then compute and display its
area using area = π × r².

## Sample run
```
Enter Radius: 7
AREA: 153.9380
```

## Concepts practiced
- Reading console input
- Safe parsing with `toDoubleOrNull()` and input validation
- Math constants (`kotlin.math.PI`)
- Arithmetic and string formatting
