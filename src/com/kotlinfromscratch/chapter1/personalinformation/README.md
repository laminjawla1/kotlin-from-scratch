# Personal Information

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 1, Exercise 1

## Problem
Design a program that prints your personal information such as:
- Fullname
- Address
- telephone number
- Email
- Major

## Sample output
Name: John Doe
Address: 742 Evergreen Terrace, Serekunda, Kanifing
Phone: +220 872 4563
Email: john.doe@example.com
Major: Information Systems

## Concepts practiced
- variables
- `val`
- String templates
