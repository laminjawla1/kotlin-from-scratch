# Sales Tax

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 1, Exercise 6

## Problem
Ask the user for a total purchase, then compute the VAT and display the
total purchase, the VAT and the total sale. Use a VAT rate of 15 percent.

## Sample run
```
Enter Total Purchase: 6000
TOTAL PURCHASE: 6000.00
VAT TAX: 900.00
TOTAL SALE: 6900.00
```

## Concepts practiced
- Reading console input
- Safe parsing with `toDoubleOrNull()` and input validation
- Constants with `const val`
- Arithmetic and string formatting
