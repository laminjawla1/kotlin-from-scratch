# Area of a Trapezoid

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 1, Exercise 8

## Problem
Ask the user for the two bases and the height of a trapezoid, then compute
and display its area using area = 0.5 × (base1 + base2) × height.

## Sample run
```
Enter base 1: 7
Enter base 2: 8
Enter height: 9
AREA: 67.50
```

## Concepts practiced
- Reading console input
- Safe parsing with `toDoubleOrNull()` and input validation
- Arithmetic and string formatting
