# Total Purchase

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 1, Exercise 4

## Problem
A customer in a store is purchasing five items. Ask the user for the
price of each item, then display the subtotal, sales tax and total.
Assume the sales tax is 6 percent.

## Sample run
```
Enter price for item one: 54
Enter price for item two: 65
Enter price for item three: 32
Enter price for item four: 45
Enter price for item five: 64
SUBTOTAL: 260.00
SALES TAX: 15.60
TOTAL: 275.60
```

## Concepts practiced
- Reading console input
- Safe parsing with `toDoubleOrNull()` and input validation
- Constants with `const val`
- Arithmetic and string formatting

## Notes
Written without a loop on purpose, since loops come later in the course.
