# Swap Two Numbers

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 1, Exercise 9

## Problem
Ask the user for two numbers, swap their values, and display the numbers
before and after the swap.

## Sample run
```
Enter First Number: 1
Enter Second Number: 2

Before Swap:
FIRST NUMBER: 1.0000
SECOND NUMBER: 2.0000

After Swap:
FIRST NUMBER: 2.0000
SECOND NUMBER: 1.0000
```

## Concepts practiced
- Reading console input
- Safe parsing with `toDoubleOrNull()` and input validation
- Swapping values with a temporary variable
- `var` for values that change
