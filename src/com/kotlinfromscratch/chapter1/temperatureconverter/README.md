# Celsius to Fahrenheit

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 1, Exercise 10

## Problem
Ask the user for a temperature in Celsius, then convert it to Fahrenheit
using F = C × 9/5 + 32.

## Sample run
```
Enter temperature in Celsius: 100
FAHRENHEIT: 212.0000
```

```
Enter temperature in Celsius: -40
FAHRENHEIT: -40.0000
```

## Concepts practiced
- Reading console input
- Safe parsing with `toDoubleOrNull()` and input validation
- Arithmetic and string formatting
