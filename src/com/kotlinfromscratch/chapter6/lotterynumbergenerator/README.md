# Lottery Number Generator

**Source:** Programming Logic and Design, Mr. Amer El-Hashemite, lecture notes, Year 1 Semester 1, Chapter 6, Exercise 2

## Problem
Generate seven random numbers between 0 and 49 and display them as a list.

## Sample run
```
LOTTERY NUMBER: [19, 8, 12, 39, 20, 35, 1]
```

```
LOTTERY NUMBER: [14, 18, 23, 4, 10, 9, 12]
```

## Concepts practiced
- Constants with `const val`
- Ranges (`0..49`) and picking a random element with `random()`
- Building a list with `List(7) { ... }`

## Notes
- Output is random, so every run differs.
- Numbers can repeat, as the second sample shows.
